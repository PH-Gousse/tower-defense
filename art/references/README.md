# References

Moodboard and sketches. Fill this by hand; nothing here is read by a script.

**Nothing from Warcraft.** No screenshot, model, icon, unit name or recognisable
look-alike from Warcraft 3 or any Blizzard title, ever. The camera and the game descend
from that map; the art does not. A reference that would fail that test is deleted, not
cropped.

Keep a `SOURCES.md` beside anything that is not your own sketch: where it came from and
under what licence. A reference is not shipped, but the habit is the same one the
manifest enforces for assets.
